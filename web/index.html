Meet Dots: Autonomous Agent Lifecycle

Dots are persistent, always-on AI agents operating within isolated cloud computers. Powered by Google Gemini and reinforced by episodic vector memory, each Dot continuously executes a 6-stage cognitive loop:

  1. Observe: Ingests messages, alerts, channel webhooks, file diffs, and environment telemetry.
  2. Think: Evaluates context with Google Gemini, recalls past episodic memories, and plans multi-step actions.
  3. Decide: Runs the Action Auto-Review risk engine to determine if execution requires human sign-off.
  4. Act: Executes Python or Bash code in dedicated sandbox containers, queries APIs, or generates deliverables.
  5. Learn: Persists execution results, human operator feedback, and verified code into vector memory.
  6. Report: Compiles executive briefings, pull requests, and deliverable artifacts.

Ineffable Empirical Discovery Engine

Inspired by AI scientist David Silver (AlphaGo, MuZero) and startup Ineffable Intelligence ($5.1B valuation), the Empirical Discovery Engine builds AI that discovers new knowledge through its own attempts, experiments, and verifiable feedback, rather than learning solely from human-written text.

The Pure Trial-and-Error Paradigm: Unlike LLMs that hallucinate solutions, the Discovery Engine executes candidate algorithms inside isolated, zero-network Python containers and grades them with mathematical ground truth (Reward > 0.9000). A solution is only marked as a "Breakthrough" if it compiles, runs, and empirically outperforms known heuristics.

Core Subsystems & Benchmarks

  • 3 Mutation Pools: Independent evolutionary populations utilize Prompt Mutation, AST Code Crossover, and Heuristic Synthesis to explore search spaces without getting trapped in local optima.
  • Online 1D Bin Packing: Synthesizes priority-scoring functions for stream item allocation, outperforming standard Best-Fit on Weibull and Gaussian item distributions.
  • Range Query Throughput: Synthesizes sub-linear O(1) query data structures that achieve 20x–50x speedups over baseline segment trees.
  • Prime Generator Invariants: Explores dense algebraic polynomials to beat Euler's classical formula (n² + n + 41) for continuous prime sequences.

AXIS Tender Intelligence & Bid Readiness

The AXIS Tender Intelligence subsystem automates the review of high-stakes public sector procurement documents across Indian government bodies (Maharashtra PWD, CPWD, NHAI):

  • 100-Page NIT Ingestion: High-speed PDF text parsing extracts NIT Reference Numbers, Authority, Estimated Cost (INR Cr/Lakhs), Earnest Money Deposit (EMD), and Submission Deadlines in under 10 seconds.
  • Indian Procurement Formulae: Automatically computes contractor Bid Capacity using the standard statutory formula:
    Available Bid Capacity = (A × N × 2) - B
    Where A is maximum annual turnover over the last 5 years, N is the project completion period in years, and B is the committed value of ongoing contracts.
  • Mandatory Compliance Audit: Verifies contractor annual turnover thresholds (minimum 100%–150% of tender value), banker solvency certificates (minimum 40%), and similar single-work completions.
  • 15 Pre-Calibrated Benchmarks: Includes authentic calibrated tenders ranging from ₹18.5 Cr state highways to ₹245 Cr NHAI Greenfield Expressways.
  • One-Click Word (.docx) Dossier: Exports client-ready Microsoft Word Bid Readiness Dossiers and Requirement-to-Evidence matrices complete with page and clause citations.

19-Layer Defense-in-Depth Security Matrix

All operations pass through strict multi-layered security controls:

  • Row-Level Security (RLS): Every database query is strictly scoped to the authenticated tenant, completely eliminating Insecure Direct Object References (IDOR).
  • Tamper-Evident WAL Audit: SQLite Write-Ahead Logging records all agent decisions with SHA-256 HMAC cryptographic signatures.
  • Action Auto-Review Gate: Categorizes operations into Low, Medium, High Risk, or Blocked. Destructive operations (e.g. dropping tables, pushing external keys) trigger the animated Approval Alert Banner requiring explicit operator approval.
  • Process Namespace Isolation: User Python scripts run with disabled network sockets and strict file access boundaries.
