ONE DOTS Official Documentation

Welcome to the official developer and operator documentation for ONE DOTS. Learn how to deploy specialist archetypes, run sandboxed code with interactive STDIN, configure 4,000+ app connectors, and enforce enterprise governance.

Meet Dots

Dots are frontier intelligence agents designed to work alongside human teams. Powered by Google Gemini 3.5, each Dot operates within a dedicated cloud computer and follows an autonomous 6-stage lifecycle:

  1. Observe: Ingests messages, alerts, channel webhooks, and environment telemetry.
  2. Think: Reasons with Gemini 3.5, retrieves episodic memory, and plans multi-step actions.
  3. Decide: Runs the Action Auto-Review risk engine to determine if human approval is needed.
  4. Act: Executes Python code, browses pages with Playwright, or queries external APIs.
  5. Learn: Persists outcomes and operator preferences into vector semantic memory.
  6. Report: Generates executive briefings and progress artifacts.

Specialist Archetypes

Organizations deploy pre-configured archetypes to handle dedicated missions:

  • Blue Dot (NOVA): Product Launch Lead — Blue face. Monitors scope changes, updates launch roadmaps.
  • Lime-Green Dot (SAGE): Research Scientist — Lime-green face with round glasses. Executes sandbox statistical runs and updates papers.
  • Golden-Yellow Dot (AXIS): Enterprise Deals — Golden-yellow face. Technical reviews, proof-of-concept generation.
  • Purple Dot (MUSE): Content & Media — Purple face. Video clip highlights, show notes, social posts.
  • Dark Navy Dot (HEX): Autonomous Software Dev — Dark navy face with glowing cyan features. Automated bug fixes, sandbox test suites, draft PRs.

Dedicated Cloud Computer & Safe STDIN

Each agent executes within a sandboxed directory with isolated process limits. To support interactive scripts like input() without freezing, the engine implements a dual-mode standard input system:

python 
# Interactive input executed in ONE DOTS Cloud Computer
name = input("Enter operator name: ")
print(f"Authenticated session for: {name}")

# Safe handling:
# 1. If STDIN provided in UI -> Reads value directly
# 2. If STDIN omitted -> Safe shim catches EOFError and defaults to 'User' in milliseconds

Action Auto-Review & Approvals

All operations pass through the Auto-Review gate. High-risk operations (such as deleting databases or deploying external keys) trigger the animated Approval Alert Banner requiring explicit human sign-off.

4,000+ App Connectors & API Reference

Connect with Slack, Teams, GitHub, and custom webhooks. Developers can also interact directly with the FastAPI server:

bash 
# List active Dots fleet
curl http://127.0.0.1:8000/api/agents

# Run code in sandbox with STDIN

     -d '{"code": "print(input())", "language": "python", "stdin": "Operator"}'
