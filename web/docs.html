Safe Standard Input (STDIN) Architecture

Unlike traditional batch runners that freeze on interactive input() calls, the DOTS Cloud Computer includes a non-interactive safe input shim alongside dedicated STDIN input fields in the workstation UI:

  • With Stdin: Characters provided in the STDIN field are passed directly into the process.
  • Without Stdin: The input shim catches EOFError and gracefully defaults to "User" in milliseconds, completely preventing 30-second execution timeouts.

Action Auto-Review & Human In-The-Loop Safeguards

Dots operate under built-in safety boundaries. The Auto-Review engine inspects proposed actions against security rules to categorize operations into autonomous execution or required human sign-off.

19 Enterprise Security & Defensive Hardening Layers

ONE DOTS is hardened according to OWASP Top 10 guidelines and strict enterprise defense-in-depth principles:

🛡️ Row Level Security (RLS)
All database queries, agents, and artifacts are strictly scoped to authenticated tenant IDs. Cross-tenant reads or writes are impossible.
📜 Tamper-Evident Audit Vault
Every administrative action, fleet deployment, sandbox code execution, and escalation decision is recorded in an immutable audit ledger.
🔑 Zero-Trust Auth On Every Route
All operational API endpoints mandate Bearer JWT or API key authentication with strict Role-Based Access Control (RBAC).
🗄️ Private Storage & Anti-Traversal
Agent sandboxes and browser screenshots are strictly private. All paths are resolved against root boundaries to defeat directory traversal.
⏱️ Sliding-Window Rate Limiting
Protects API endpoints with tiered rate limits, returning standard HTTP 429 and Retry-After headers to prevent compute abuse.
🧩 Cryptographic CAPTCHA
Public deployment forms and ingress actions are protected by signed human-verification challenges without third-party trackers.

FastAPI Standalone Management Endpoints

Developers can automate Dot provisioning and telemetry via standard REST endpoints:

bash 
# List active Dots fleet
curl http://127.0.0.1:8000/api/agents

# Trigger immediate autonomous step
curl -X POST http://127.0.0.1:8000/api/agents/{agent_id}/tick

# Execute Python in dedicated cloud computer with stdin
curl -X POST http://127.0.0.1:8000/api/agents/{agent_id}/execute \
     -H "Content-Type: application/json" \
     -d '{"code": "print(input())", "language": "python", "stdin": "Frontier"}'

# Review pending human approval decisions
curl http://127.0.0.1:8000/api/decisions/pending
